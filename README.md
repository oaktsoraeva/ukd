# Прототип «Новый УКД»

Кликабельный прототип создания универсального корректировочного документа
в разделе ЭДО Точки. Собран по странице Figma
[«ЭДО · Типы документов» → «🚧 УКД»](https://www.figma.com/design/8hBwa9wtjAwdIyugUFOrtN/?node-id=4421-27816).

Бэкенда нет: всё состояние живёт в `ukd/src/App.tsx`, данные — фикстуры
в `ukd/src/data.ts`.

## Структура

```
design-system/   вендоренная копия UI-кита Точки, подключается через алиас @ds
ukd/             сам прототип
```

Дизайн-система лежит рядом, потому что прототип ссылается на неё
относительными путями: алиас `@ds` в `ukd/vite.config.ts` и `ukd/tsconfig.json`,
импорты токенов в `ukd/src/index.css`. Из кита взято только то, что нужно для
сборки, плюс `AGENTS.md` — в нём описаны соглашения и каталог компонентов.

## Запуск

```bash
cd ukd && npm install && npm run dev
```

Подробности про сам сценарий, свои компоненты и список допущений —
в [`ukd/README.md`](ukd/README.md).

## Деплой

Корневой `vercel.json` собирает `ukd/` и отдаёт его с корня сайта.

## История

Прототип разрабатывался в репозитории
[oaktsoraeva/prototypes](https://github.com/oaktsoraeva/prototypes) рядом с
